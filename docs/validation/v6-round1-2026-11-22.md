## 5. 编译风险清单（交给 Claude Code）

行号为当前文件内的行号。

| 文件 | 行 | 风险 | 建议修法 |
| :--- | :--- | :--- | :--- |
| `Tokens/BSMotion.swift` | 9–15 | `Spring(response:dampingRatio:)` 初始化器名称依据文档记忆，未对照 SDK 确认 | 如报错，改用 `Spring(duration:bounce:)`：response 0.35/阻尼 1.0 ≈ `duration: 0.35, bounce: 0`；阻尼 0.8 ≈ `bounce: 0.2` |
| `Tokens/BSMotion.swift` | 24 | `.spring(spring)` 可能在 `spring(_:blendDuration:)` 与 `spring(_:gestureVelocity:)` 间有歧义 | 改为 `Animation.spring(spring, blendDuration: 0)`，或 `Animation(spring)` |
| `Tokens/BSMotion.swift` | 32–47 | `BSPressableStyle` 是 public struct 且含 `@Environment`；若 `ButtonStyle` 在当前 SDK 要求 `Sendable` 会报错 | 去掉 `@Environment`，改为在 `makeBody` 里返回一个私有子视图（子视图读取环境值） |
| `Tokens/BSMotion.swift` | 43 | `.contentShape(.rect)` 依赖 `Shape.rect` 静态成员 | 改为 `.contentShape(Rectangle())` |
| `Tokens/BSText.swift` | 24–26 | switch 表达式里 `.system(_:design:weight:)` 隐式成员链加 `.monospacedDigit()` | 改写为 `Font.system(...)` 显式类型 |
| `Tokens/BSText.swift` | 35–60 | `ViewModifier.body` 带 `@ViewBuilder` 和 `@Environment`；`HierarchicalShapeStyle.primary/secondary` 三元表达式 | 若类型推断失败，拆成 `private var secondaryStyle: HierarchicalShapeStyle` 计算属性 |
| `Tokens/BSText.swift` | 46 | `.contentTransition(.numericText())` | 需要 iOS 17 / macOS 14，包的下限满足；如报参数错误改 `.numericText(countsDown: false)` |
| `Tokens/BSColor.swift` | 全文件 | macOS 分支使用 `NSColor.underPageBackgroundColor` / `.systemGray` | 如 macOS 构建报错，换成 `.windowBackgroundColor` / `.gray` |
| `Tokens/BevelTheme.swift` | 9 | 仅改了阻尼数值，无编译风险；视觉上分数数值变化动画不再回弹 | — |
