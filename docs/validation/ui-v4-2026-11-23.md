## 7. 与规格不一致的地方及原因

1. **趋势纵览列表只有 5 项分数，缺"夜间 HRV""实睡时长"两行**。`ChartSeriesSnapshot` 以 `MetricKind` 为键，这两项需要把快照构建泛化为任意序列（含非 0–100 的纵轴），本轮没有做。
2. **今日记录的训练行没有"待复盘 / 已复盘"**：`TodayFeature` 没有训练复盘状态，需要新增 reducer 状态。现在显示"名称 · 时间 · 时长"。
3. **健身"计划变更带撤销"没有做**：`AppActionCatalog` 里 `adjustPlan` 的 `isUndoable` 为 `false`（按 C 级处理，不会自动应用），没有可撤销的"已应用计划变更"可列。待执行器支持后再接。待确认的课表提案卡仍保留。
4. **健身标题栏没有"补录"按钮**：现有代码没有对应动作，只放头像。
5. **营养餐次点开是原地展开，不是餐次详情页**；描述只写"N 项"，不列食物名（UI 测试要求折叠时看不到食物名）。"饮食建议"沿用现有 `deterministicAdviceSummary`（已点名营养素，本来就没有"暂时无法判断"），没有改写 `DailyBrief` 的生成逻辑。
6. **Coach 页仍用系统 inline 导航栏**（聊天页，高度已是一行），没有改用 `BSPageHeader`。
7. **提示词只减了约 28%，没有减半**：保留了必须的工具清单、三级授权、四态与 `recentAdequacy` 等现有测试依赖的字段。结构（结论 → 原因 → 建议）、确定语气、禁用套话已按 §6.2 写入。
8. **核对器的"四舍五入"是对工具 JSON 里任意数字做同精度取整比较**，比"同指标"更宽松；评测里 `unverified_rate` 因此可能偏乐观。差值只在带类型化证据的同指标同单位内计算。
9. **趋势大图的"7 天 / 30 天折线，6 个月 / 3 年胶囊"改动在 `TrendHorizonChart`**，指标详情页的图也随之改变（30 天原为胶囊）。
10. 旧缓存的图表快照没有逐点区间字段（新增字段为可选，解码不会失败），在下一次重算前图表不画平时范围。
11. 横向锁定手势用自定义 `UIGestureRecognizer`；模拟器 UI 测试只验证了"轻点选点"，真机拖动手感没有自动化验证。
12. 预览模式下"示例数据"标签已去掉；规格说可以在设置里看到数据来源，我没有核对设置页是否显示。
