## 2. 内置行为

- **四态与骨架**：数据组件都接受 `MetricAvailability`；缺失、排除显示 `--` 加原因，已知为零显示 `0` 加原因；`isLoading` 为 `true` 时 `.redacted(reason: .placeholder)`。
- **按压反馈**：可点击元素统一走 `BSPressableStyle`（`bsTappable`、`BSNavRow`、`BSSection` 的按钮等）。
- **减弱动态效果**：分数环、摄入环的动画走 `BSMotion.animation(_:reduceMotion:)`；按压缩放在该设置下关闭。
- **降低透明度**：`BSAskCoachButton` 改为 `surface` 实底加描边；macOS 15 没有 Liquid Glass，也用实底。
- **增强对比度**：`BSCard` 加描边；`bsText(.label / .caption)` 的二级文字升为一级。
- **区分颜色**：分数环在该设置下名称前加领域图标；走向标签始终有图标和文字；`BSDeltaBadge` 用箭头而不是红绿色。
- **触觉**：`BSActionRow` / `BSReceipt` 在状态变为完成 / 失败 / 已撤销时触发 `.success` / `.error` / `.impact(light)`（仅 iOS）。

## 3. 未完成或有意简化的地方

- 圆环估算画法：dataviz 规定虚线只表示估算；`BSIntakeRing` 用较淡的填充（`BSOpacity.muted`）表示估算，没有画虚线环。
- `BSChartCard` 只做外壳，不改现有 8 个图表；画廊里用内部的 `BSMiniLine` 当示例图。
- 没有接入每个图表的 `AXChartDescriptorRepresentable`（属于图表重画阶段）。
- `BSBodyMap` 不在本轮范围（依赖 MuscleMap 包，需要 Features 层数据）。
