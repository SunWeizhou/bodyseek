# V6 第五轮：每日简报（2026-11-22）

## 设计

依据 ADR 0021：每天只有一份 `DailyBrief`，所有页面只引用它，不再各自产出结论。

- **对象**：`DailyBrief`（`dayKey`、`generatedAt`、`modelInputsDigest`、`engine`、`headline`、`changes`、`actions`、`pageNotes`、`evidence`）。`pageNotes` 的键是 `BriefPage.rawValue`，没有专门文案时 `note(for:)` 退回一句话结论。
- **引擎顺序**：云端 → Apple 端侧 → 本地模板。云端或端侧失败，或输出含"未核实数字"时回落到下一个；本地模板一定能产出，离线可用。
- **数字溯源**：`DailyBriefVerifier` 用 `NumericProvenanceVerifier` 检查简报文字里的每个数字，必须能在 `BriefInputs.provenanceJSON` 里找到。本地模板的数字全部可核实（有测试）。
- **缓存**：按 `modelInputsDigest` 缓存到 `daily_brief` 表。输入变化 → 旧简报标记过期 → 重新生成；过期简报可立即显示（`latest`）。
- **反馈**：`BriefFeedbackBar`（准 / 不准 / 没用），一天一次，写入 `brief_feedback` 表。
- **页面接入**：营养页、趋势页的"AI 解读"槽位改读 `pageNotes`（`dailyBriefUpdated` 动作）；`generatePageInsight` 保留在 `CoachAIClient`，但这两页不再调用。今日页读 headline、changes、actions。
