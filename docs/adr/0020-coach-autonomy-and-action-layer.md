# 0020. Coach 高度自主与分级动作层（AppAction）

- **Status**: Accepted
- **Date**: 2026-11-22
- **Supersedes / Updates**: 取代 [ADR 0008](0008-ai-proposes-user-confirms-plan-changes.md) 中「AI 只能提案、重要修改必须经用户显式确认」的授权部分；ADR 0008 中「确定性本地证据生成正式计划、AI 不得静默覆盖已评分证据与安全边界」的部分继续有效。
- **Source**: [V6 重构蓝图](../design/v6-blueprint.md) §1 原则 P3、§3.3；批准人：项目负责人（2026-11-22）。

> 实施状态：本 ADR 确定目标授权模型。动作层 `AppAction` 尚未实现，将在蓝图第 2 阶段（读写通路）落地。在此之前，V5 现有的 `ActionProposal` + `ActionExecutor`「提案 → 用户确认 → 单事务写入 + `action_audit`」流程保持原样，仍是代码的实际行为；本 ADR 不要求任何一次性改写。

## Context

ADR 0008 把 AI 定位为「只能提案」，所有重要修改都要用户显式确认。V5 实现里这一规则表现为三个 `propose_*` 工具加确认卡片。

项目负责人在 2026-11-22 明确选择 **Coach 高度自主**：Coach 应该能替用户操作整个 App，而不是每次都等待确认。但自主与安全必须同时成立，现状有三个缺口：

1. 页面按钮和 Coach 写入各走各的路径，各个 Reducer 自己写库，刷新靠 `AppFeature` 手工协调，没有统一的审计与撤销。
2. 「确认」被用在几乎所有写入上，低风险动作（例如记一餐）也要弹确认，违反设计系统「确认只留给不可逆的操作」（Apple 的 Agency 原则）。
3. 高度自主需要更强的事后保障：任何动作都要能看到、能撤销。

## Decision

### 1. 所有写入统一走动作层 `AppAction`

页面按钮和 Coach 调用同一套 `AppAction`。每个动作都必须定义：

- 输入 schema；
- 风险级别（A / B / C）；
- 前置校验；
- 单事务执行；
- 审计快照（before / after）；
- 撤销逻辑。

由现有 `ActionProposal` + `ActionExecutor`（v5 审计与撤销）扩展而来，不重写。Coach 通过一个 `execute_action(AppAction)` 工具写入，取代三个 `propose_*` 工具。

### 2. 三级授权

| 级别 | 行为 | 例子 |
| :--- | :--- | :--- |
| **A 自动执行** | 直接执行，回执里给出撤销按钮 | 记一餐、补训练标注、记录打卡、保存记忆、跳转页面、开始或结束一个实验 |
| **B 自动执行并突出提示** | 直接执行，展示改动前后对比，24 小时内可撤销 | 修改训练计划、修改营养目标、修改睡眠目标、停用记忆 |
| **C 必须确认** | 先出提案，用户确认后才执行 | 删除记录、批量操作、清空数据、写回 Apple 健康、向云端发送新的数据类别 |

### 3. 保持不变的底线

- 原始 HealthKit 采样数据永不上云；「向云端发送新的数据类别」永远是 C 级。
- 数字由本地确定性模型计算，Coach 只读不算（见 [ADR 0021](0021-body-model-layers-and-daily-brief.md)）；动作的数值参数必须能溯源到工具结果。
- 动作失败不得被吞掉，回执必须显示失败原因。
- 新增动作时先定级，拿不准的按更高一级处理；升级级别需要更新本 ADR 的表格。

### 4. 用户控制面

设置中提供：各级别的总开关、「本周 Coach 做了什么」审计页、一键撤销最近一次操作。

## Consequences

- 对话和页面的写入体验统一：A/B 级不再弹确认，用户通过回执和撤销保持控制，C 级才弹确认。
- 跨页刷新不再依赖 `AppFeature` 手工协调，由动作层写库加数据库观察完成（蓝图第 2 阶段）。
- 实施前，`CLAUDE.md` 第 3 节「不得在对话回合内静默写库」仍按 V5 现状执行；动作层上线并通过端到端测试（「Coach 一句话记一餐 → 营养页刷新 → 撤销」）后，该条款随之更新。
- 风险：高度自主可能误写数据。应对：A/B 级全部可撤销，C 级必须确认，审计页可见，任何动作都能一键撤销（蓝图 §9）。
- ADR 0008 正文不修改；索引中标注「授权部分被 0020 取代」。
