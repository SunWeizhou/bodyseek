# BodySeek 视觉系统升级 · 2026-09-22

依据用户本次反馈：保留 A 的信息结构，减少小字；审美参考 Apple、Bevel、ChatGPT。以下为本次实现方向，不宣称用户已确认最终品牌。

- 字体：iOS 系统字体，标题 semibold，正文 regular；主内容优先 17 pt、次级内容 15 pt。取消首页指标的装饰字形，不用衬线标题或 rounded 数字。
- 颜色：浅色画布 #F5F5F7，深色 #111113；白/深灰卡面。行动蓝 #175CD3 / #91BAFF。恢复、睡眠、负荷、压力、能量仍各自具有语义色，不让品牌蓝表达身体好坏。
- 形状：标准卡 20 pt、重点卡 24 pt；连续圆角。页面左右 20 pt；44 pt 最小触控区域。首页三项并排环 + 两项横向卡，大字号改纵向。
- 标记：新增原生 `BodySeekContour` 单笔 B 轮廓，字标使用 system semibold。本轮仅替换 App 内通用品牌组件和依据页；既有 AppIcon/LaunchMark 资产保留，完整资产定稿仍待视觉反馈。
- Today：五项状态 → 一句本地解释 → 下一项安排 → 感受反馈。完成动作后不重复派发；空计划与全部完成不同。
- Trends：时间范围 → 主要发现 → 五项趋势 → 图表。缺失日保留空档；预览曲线明确标示示例，永不写入健康数据库。
- Plan：保留用户行动和编辑能力，去掉口号式重复标题；保存失败不关闭草稿。
- Coach：大标题、紧凑日期与状态摘要、三个问题入口；移除重复五环仪表。
- 文案减法不移除错误、缺失、历史日期、证据或权限边界。详细解释留在详情和依据页。

## 产物

- `index.html` 是独立、无联网健康请求的 HTML 设计原型，`?variant=A` 为用户选定结构的修订版。
- `native.html` 展示从本次 Xcode UI 测试导出的真实 SwiftUI 页面（全部使用示例输入）。
- 验收命令、结果和限制见对应 GitHub Pull Request；`native.html` 的图片来自真实 SwiftUI 模拟器测试，使用示例输入。
