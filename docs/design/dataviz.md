## 0. 现有图表为什么难看

对 `BodySeekDesign/Charts` 下 14 个文件的统计：

| 问题 | 证据 | 带来的观感 |
|---|---|---|
| **每张图叠了太多层** | `TrendLineChart` 一张图叠了 9 层：基线带、中位虚线、排除带、渐变面积、折线、零值点、选中竖线、选中点、最新点 | 看不出重点，"信息很多但读不出结论" |
| **线宽没有刻度** | 14 种线宽：0.5、0.75、1、1.1、1.2、1.3、1.4、1.5、1.6、1.8、2、2.1、2.2、2.3 | 每张图粗细都差一点，拼在一起就乱 |
| **透明度没有刻度** | 20 种以上透明度：0.01–0.75 | 同一个颜色在不同图里深浅不一 |
| **虚线滥用** | 3 种虚线样式共 16 处：中位线、选中线、预测线、参考线都是虚线 | 虚线读起来像"草稿"；而且虚线本该表示"估算"，现在失去了这个含义 |
| **渐变面积填充** | 4 个图表在折线下面铺渐变（`TrendLineChart`、`EnergyAreaChart`、`ForecastFanChart`、`MiniSparkline`） | 典型的"模板仪表盘感"；面积从 Y 轴下界铺起，还会暗示数值从 0 开始 |
| **领域色被冲淡成"脏色"** | 胶囊图未选中的柱子用领域色 × 0.34 透明度 | 颜色发灰发闷，不像是故意设计的 |
| **语境元素和数据抢颜色** | 基线带、选中线都染成领域色 | 基线带和数据看起来同样重要 |
| **图表卡变成文字卡** | `TrainingLoadDashboardCard` 有 22 段文字、24 处字体设置 | 图被文字淹没 |
| **同一种图有两套实现** | 睡眠分期同时用了 `SleepChartKit` 和自绘 `Canvas` | 今日页和详情页的睡眠图长得不一样 |

**对照 Apple 健康**：它的图表几乎都遵循同一个配方：
- 图上方是统计头：标签、大数字、单位、日期范围。
- 数据只用一种颜色。
- 网格线极淡，刻度标在右侧。
- 没有渐变。
- 选中某个点时，统计头直接变成这个点的值，不弹浮动气泡。

**这个配方 BodySeek 完全可以照搬。**

## 1. 六条原则

| # | 原则 | 规则 |
|---|---|---|
| V1 | **一张图回答一个问题** | 卡片标题写清问题范围（如"夜间 HRV · 30 天"），答案写在统计头里。一张卡只放一张图。 |
| V2 | ~~数据用颜色，语境用灰色~~（**已作废**，见 [ui-v4-integration §1.2](ui-v4-integration.md)） | 原规则"过程用灰色、只有结论用颜色"作废：迷你图、纵览列表、走向行的迷你线一律使用对应领域色；基线带（"平时范围"）、网格、参考线仍用中性灰。 |
| V3 | **一个主图层，最多两个语境层** | 主图层是折线、柱或胶囊之一；语境层最多两个，从基线带、一条参考线、排除带中选。其余全部删掉。 |
| V4 | **不做装饰** | 不用渐变、阴影、发光、3D。唯一的面积图是能量电量（它表示"储量"），用纯色浅填充，不用渐变。 |
| V5 | **虚线只表示预测，估算用斜纹**（v4 修订） | 虚线只用于"预测"：预测段、未来 2 小时的能量估算。**AI 估算一律用 45° 斜纹**（领域色细线 + 透明间隔，`BSStripeFill`），已记录部分用实色，适用于营养热量条、宏量营养素条、热量柱。被排除的时段用中性灰块并写明原因。缺失数据画成断开，中位线不画或改为实线细线。 |
| V6 | **选中就是聚焦** | 选中的元素保持领域色，其余元素降为灰色；统计头换成选中项的值。不用浮动气泡，松手后读数保留。 |

## 2. 图表令牌 `BSChart`

所有数值都从设计系统第 2 章的令牌推导，图表代码里不允许再出现数字。

### 2.1 线与点

| 令牌 | 值 | 用途 |
|---|---|---|
| `grid` | 0.5pt，`separator` 色 | 横向网格线 |
| `rule` | 1pt | 参考线、选中竖线（实线，`.tertiary` 色） |
| `data` | 2pt，圆角端点和连接 | 主折线 |
| `micro` | 1.5pt | 迷你折线 |
| `dot` | 直径 6 | 数据点（只在 7 天视图或稀疏数据时画） |
| `focus` | 直径 10，外加 2pt `surface` 色描边 | 选中点、"今天"点 |
| `estimateDash` | `[4, 3]` | **全 App 唯一的虚线样式**，v4 起只用于预测；AI 估算改用斜纹（`BSStripeFill`） |

### 2.2 柱与胶囊

| 规则 | 值 |
|---|---|
| 柱宽 | 由组件根据点数计算，柱间距不小于柱宽的 40% |
| 胶囊圆角 | 柱宽 ÷ 2（两端全圆） |
| 普通柱顶部圆角 | `BSRadius.s` 与柱宽 ÷ 2 中的较小值，只圆顶部 |

### 2.3 颜色角色

| 角色 | 取值 | 用途 |
|---|---|---|
| `data` | 领域色 `solid` | 主图层 |
| `dataSoft` | 领域色 × `BSOpacity.faint` | 能量面积、预测区间带 |
| `dataEstimate` | 领域色 45° 斜纹（`BSStripeFill`） | 进度条和柱里的估算部分（v4：取代 `muted` 纯色） |
| `context` | 系统 `tertiarySystemFill` | 基线带（"平时范围"）、排除带、环形轨道 |
| `dimmed` | 系统 `systemGray4` | 选中状态下其余的数据 |
| `axisLabel` | `.tertiary` 文字色，`caption2` 字号 | 坐标刻度 |

**营养**不属于五个领域，营养页的数据统一使用全局强调色 `tint`（即恢复绿）。

**圆环线宽**：`ringL` 112 用 10pt，`ringM` 64 用 7pt，`ringS` 28–44 用 4pt。

**睡眠四期**（同一色相的明度阶梯，清醒用灰色）：

| 阶段 | 浅色 | 深色 |
|---|---|---|
| 清醒 | `#C7C7CC` | `#48484A` |
| REM | `#9E9CF5` | `#C4C3FF` |
| 核心 | `#5E5CE6` | `#8F8DFF` |
| 深睡 | `#3634A3` | `#5E5CE6` |

**心率区间 Z1–Z5**：负荷色的 5 级明度阶梯（由浅到深），不用彩虹色。

**周期走向**：沿用设计系统 2.3 的定义：变强用恢复色，稳定用二级灰，透支用负荷色，恢复中用睡眠色，数据不足用三级灰。

### 2.4 坐标轴

- **Y 轴**：只画 3 条横向网格线（取整后的最小值、中间值、最大值），刻度标在右侧；不画轴线和刻度线。
- **X 轴**：最多 4 个刻度，沿用 chart-grammar 3.1 的规则；不画竖向网格线。
- 0–100 的分数，Y 轴固定为 0、50、100。

### 2.5 尺寸

图表高度只能取设计系统 `BSSize` 中的四档：`chartMicro` 32、`chartCompact` 120、`chartStandard` 200、`chartDetail` 280。

## 3. 统计头 `BSChartHeader`

每张 `BSChartCard` 的图表上方都有统计头，格式完全照搬 Apple 健康：

```
平均                              ↓ 4 ms vs 前 28 天
52 ms
10月24日–11月22日
```

| 位置 | 内容 | 文字角色 |
|---|---|---|
| 标签 | 平均 / 范围 / 总计 / 最新 / 实睡 | `label` |
| 数值 + 单位 | `52` + `ms` | `number` + `label` |
| 日期范围 | 本周期，或选中的那一天 | `caption` |
| 右侧（可选） | `BSDeltaBadge` 与基线比较，或一个次要读数 | `label` |

**选中时**：标签变成选中项的日期（如"11月18日"），数值变成选中值，右侧出现"清除"。松手后保持，点"清除"或切换周期后恢复默认。

| `FitnessFatigueChart`（新） | 练得是在积累还是在透支 | 两条线：体能（负荷色）、疲劳（灰色） | — | 图例（改为在线尾直接标名称） | 统计头显示体能、疲劳和状态差 |
| `ZoneBar` | 这次训练强度怎么分布 | Z1–Z5 比例条（负荷色阶） | — | 彩色区间 | — |
| `MiniSparkline` | 近期趋势是升还是降 | 1.5pt 折线 + 末端点 | — | 面积、基线带 | 不可交互 |
| `BSVerdictGrid`（新） | 这个周期身体在变强还是透支 | 每条轴一行：名称、依据、走向标签、12 周迷你折线（灰色，末端点用走向色） | — | — | 点击进入该轴的趋势图 |
| `BSIntakeRing`（新） | 今天吃了多少、还差多少 | 热量环 + 三条宏量营养素胶囊进度条 | 轨道 | 一级页面上的 29 项微量营养素 | — |
| `ProgressChart`（新，e1RM） | 这个动作有没有在变强 | 每次训练一个点 + 2pt 折线 | — | — | 统计头显示日期、e1RM、重量 × 次数 |
| `ForecastFanChart` | （实验室）明天会怎样 | 历史实线 + 预测虚线 | 80% 区间（`dataSoft`） | 90% 区间、预测柱 | 统计头显示预测值和区间 |
| `PatternForestChart`、`FeatureAttributionChart` | （实验室）哪些因素有关联 | 点 + 区间线 | 零参考线（1pt） | 渐变、多色 | — |
| `TrainingLoadDashboardCard` | — | **拆分**：数字进统计头，图进 `BSChartCard`，卡内文字不超过 5 行 | — | — | — |

### 4.1 四态在新画法里的表现

沿用 chart-grammar 第 5 章的语义，只调整画法，让它们和 V5 保持一致：

| 状态 | 折线、柱 | 圆环 |
|---|---|---|
| 有数据 | 正常绘制 | 正常绘制 |
| 已知为零 | 在 0 处画空心点 | 只画轨道，中间写 `0`，下方写原因 |
| 缺失 | 断开，不连线；图下写覆盖率 | 只画轨道，中间写 `--`（**不再用虚线空环**，因为虚线只表示估算） |
| 排除 | 中性灰块（`context`）+ 文字说明原因 | 只画轨道，中间写 `--` + 原因 |

## 5. 交互

| 行为 | 规则 |
|---|---|
| 选点 | 拖动时 1:1 跟随手指；每跨过一个数据点触发一次 `.selection` 触觉反馈 |
| 读数 | 统计头替换为选中值；**不用浮动气泡**，避免手指遮挡数据 |
| 松手 | 读数保持；轻点空白处或"清除"后恢复默认 |
| 切换周期 | 沿时间方向过渡（切到更长周期时，内容向左收），使用 `BSMotion.standard` |
| 首次出现 | 数据从基线向上生长，使用 `BSMotion.standard`；减弱动态效果时改为淡入 |
| 数值变化 | `.contentTransition(.numericText())` |

## 6. 无障碍

- 每张图都实现 `AXChartDescriptorRepresentable`，VoiceOver 可以逐点朗读。
- **区分颜色**：睡眠泳道左侧写阶段名；走向标签同时带文字，不只靠颜色。
- **增强对比度**：网格线改为 1pt；刻度文字从三级色升为二级色。
- **减弱动态效果**：所有生长和过渡动画改为淡入。

## 8. 落地

1. 在 `BodySeekDesign/Tokens/` 中新增 `BSChart` 令牌（第 2 章）。
2. 新增 `BSChartCard` 和 `BSChartHeader`，现有 8 个图表组件全部改为放在它们里面。
3. 按第 4 章逐个重画组件。顺序：`TrendLineChart` → `RangeCapsuleChart` → `MiniSparkline` → `SleepStageChart` → `IntradayBarChart` → `EnergyAreaChart` → 新组件。
4. 删除 `LoadRecoveryComboChart` 和 `SleepChartKit` 依赖。
5. 设计门禁（设计系统 10.3）增加三条图表规则：

| 规则 | 检测方式 | 现有违例数 |
|---|---|---|
| 图表内禁止渐变 | `Charts/` 下出现 `LinearGradient` | 4 |
| 线宽只能取令牌 | `Charts/` 下 `lineWidth:` 后面跟数字 | 46 |
| 虚线只能用 `estimateDash` | `dash: [` | 16 |

6. 每个组件都加入 Gallery，覆盖四态、浅色/深色、默认/最大字号。
